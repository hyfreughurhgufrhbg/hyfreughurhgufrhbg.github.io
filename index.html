🌊 sar-flood-segmentation - Map Floods From Satellite Images

A free program for Windows that takes satellite radar pictures of the Earth and turns them into simple, colour-coded flood maps. It was built as an MSc dissertation project at the University of Hull and compares two different artificial-intelligence approaches to finding water in pictures taken from space.

🛰️ What This Software Does

Floods are difficult to track from the ground, especially in remote areas or during heavy storms. Satellites solve part of that problem: they can photograph huge areas of land in a single pass. But there is a catch. Ordinary photographs are useless at night and useless through thick cloud, which is exactly the weather you get during a flood.

This software works with a different kind of satellite picture called SAR (Synthetic Aperture Radar). Radar pictures are taken with radio waves instead of light, so they work perfectly at night and see straight through cloud. The downside is that radar images look like noisy grey static to a human being. Water and land are hard to tell apart with the naked eye.

That is the job of this program. It reads a radar image and produces a segmentation map — a picture where every pixel is labelled either "flooded" or "not flooded". The result is a clean, easy-to-read map you can look at in any ordinary image viewer.

The project also does something more scientific. It compares two families of AI models — traditional convolutional networks (U-Net style) and modern Transformer models (SegFormer style) — and reports how well each one performs when it is asked to map floods in places it has never seen before. All of this is tested on the well-known Sen1Floods11 benchmark dataset.

🖥️ Your First Run, Step by Step

When the window opens you will see a simple layout: an area for your input image, a preview panel, and a set of buttons. Here is the easiest way to get a result.

  1. Choose a sample image. Click the input area and browse to the folder called samples that came with the program. Pick any of the radar images inside it.
  2. Preview it. The image appears in the preview panel. It will look grey, grainy and quite noisy. That is completely normal for radar data.
  3. Pick a model. Use the model selector to choose either the U-Net model or the SegFormer model. If you are unsure, start with U-Net — it is faster.
  4. Press the map button. The program will work through the image. On a typical laptop this takes somewhere between a few seconds and a minute.
  5. Look at the result. A new picture appears next to the original. The overlay shows where the model believes water is present.
  6. Save your map. Use the save button to store the result anywhere you like. It saves as a normal image file you can open, print or email.

To try your own data, replace the sample image with any Sentinel-1 radar image you have downloaded from a satellite data service. The program accepts standard image files and will resize them automatically.

🗺️ Reading Your Flood Map

The output is deliberately simple so that anyone can understand it without training.

  • Highlighted areas show water that the model has detected. These are the flooded zones.
  • Plain, unhighlighted areas are land the model considers dry.
  • Faint or patchy edges along a boundary usually mean the model was uncertain — this commonly happens around riverbanks and wet fields.

No automated map is perfect. Radar can struggle with very calm water, with dense city buildings and with steep hills. Treat the output as a strong first draft that helps you see the big picture quickly, rather than as a legal or safety-critical record.

🧠 The Two Models Compared

The heart of the dissertation is a fair comparison between two very different ways of teaching a computer to recognise water.

The U-Net approach (convolutional network). This is the classic workhorse of image analysis. It scans the picture in small overlapping windows and learns simple patterns first — edges, textures, brightness — then combines them into larger shapes. It is compact, predictable and very fast to run on ordinary hardware.

The SegFormer approach (Transformer network). This is a newer design that looks at the whole picture at once and learns which parts relate to which. It can capture long, connected shapes such as a river valley filling up, which the window-based approach sometimes misses. The trade-off is that it needs more computing power.

The key question the project answers is cross-geographic performance: when a model is trained on floods in one part of the world, how well does it cope with floods somewhere completely different? The comparison report included with the download lays out the scores side by side so you can see the answer for yourself.

🔧 Troubleshooting

The program window closes immediately. This usually means the start file has been separated from its folder. Move it back inside the extracted folder and try again.

Windows shows a warning when I open the file. This is normal for software downloaded from the internet. Choose the option to run it anyway. If you prefer, you can right-click the file, open its properties and tick the box to allow it.

The mapping step takes a long time. Large images need more time. Try a sample image first to confirm everything works, then work up to bigger pictures. Closing other open programs also helps considerably.

The result looks blank. Check that you selected a radar image rather than a normal photograph. Radar files often have long, technical names; the sample folder shows what a valid file looks like.

You need more storage space. Delete the sample data folder once you are comfortable with the program. It can always be downloaded again should you need it.

Which model should I choose? Start with U-Net for speed. Switch to SegFormer when you want the very best detail on large, connected flooded areas.
